These numbers are estimated from GitHub’s public download counters, as there is no tracker or telemetry in the app. Updated ….

  • Estimated installs: downloads of the app from GitHub.
  • Estimated daily users: since version 1.0.8, Helix checks once a day for updates by downloading a tiny file from GitHub, which counts each download. Dividing those checks by the number of days gives the Macs that open Helix on an average day. Someone who uses Helix once a week only counts that day, so more people use Helix than this number.
